# samimi Gems — نسخه وب (GitHub Pages)

نسخه وب مستقل ربات تلگرام [samimi-gems-bot](https://github.com/Mar-mir/samimi-gems-bot):
چند دستیار شخصی (Gem) با پرامپت دلخواه، مثل Gemهای جمینای — حالا به‌صورت
یک وب‌سایت استاتیک، بدون سرور و بدون ثبت‌نام.

## چی دارد (همان منطق ربات)

- **جم‌ها:** ساخت / ویرایش / حذف دستیار، هر کدام با **پرامپت (System Prompt)**،
  **دانش ضمیمه** (متن یا فایل `.txt` / `.md`، مثل ربات) و **کلمات ممنوعه**
  (هر خط یک مورد — هم به پرامپت اضافه می‌شود، هم بعد از ساخت پاسخ بررسی می‌شود).
- **کلید خودت (BYOK):** هر کاربر کلید پروایدر خودش را در تنظیمات می‌گذارد.
  کلید فقط در `localStorage` همان مرورگر می‌ماند و جز به پروایدر، به هیچ
  جایی فرستاده نمی‌شود. بدون کلید، پاسخی نمی‌رسد.
- **کپی + دوباره بساز:** زیر هر پاسخ دکمه **📋 کپی** (متن پاسخ دست نمی‌خورد)
  و **↻ دوباره بساز** هست؛ پاسخ شامل کلمه ممنوعه با نشان ⚠️ مشخص می‌شود.
- **مدل‌ها:** پیش‌فرض `muse-spark-1.3-contributor` روی روتر Nara
  (`https://router.bynara.id/v1`) با همان زنجیره fallback ربات؛ اگر مدل اصلی
  خطا داد، خودکار سراغ مدل‌های رایگان بعدی می‌رود. لیست مدل‌های رایگان را
  می‌شود از تنظیمات بروز کرد. حافظه مکالمه: ۲۰ پیام آخر (مثل ربات).
- **جم پیش‌فرض:** همان `reply guy ✍️` ربات، با همان پرامپت و همان لیست
  کلمات ممنوعه (Exactly ،game changer ،Let's dive in و…).
- **خروجی/ورودی:** Export/Import همه جم‌ها و گفت‌وگوها به‌صورت JSON.
- **تم:** برگرفته از قالب MONVÉL در Framer — پس‌زمینه کرم `#F2EFEA`،
  متن مشکی، اکسنت نارنجی سوخته `#C9874A`، فونت Jost برای تیترهای لاتین
  و Vazirmatn برای فارسی.

## انتشار در GitHub Pages (۵ دقیقه)

۱. یک ریپوی جدید در گیت‌هاب بساز (مثلا `samimi-gems-web`) و فایل‌های همین
   پوشه را پوش کن:
   ```bash
   git init
   git add .
   git commit -m "samimi Gems web"
   git branch -M main
   git remote add origin https://github.com/<username>/samimi-gems-web.git
   git push -u origin main
   ```
   (فایل‌های لازم: `index.html` ،`styles.css` ،`app.js` ،`favicon.svg` ،`.nojekyll`
   و پوشه `proxy/` — هیچ مرحله build لازم نیست.)

۲. در گیت‌هاب برو به **Settings → Pages**، بخش **Build and deployment**،
   Source را **Deploy from a branch** بگذار، Branch را **main** و پوشه را
   **/ (root)** انتخاب کن و Save بزن.

۳. بعد از حدود یک دقیقه سایت بالا می‌آید:
   `https://<username>.github.io/samimi-gems-web/`

## ⚠️ نکته مهم درباره CORS (بخوان!)

روتر Nara هدر `Access-Control-Allow-Origin` نمی‌فرستد — من با curl و
preflight بررسی کردم: پاسخ `OPTIONS` بدون این هدر برمی‌گردد. یعنی مرورگر
جلوی تماس **مستقیم** از GitHub Pages را می‌گیرد (خطای `Failed to fetch`)،
در حالی که curl و ربات تلگرام مشکلی ندارند. این محدودیت سرور است و با
تغییر کد فرانت‌اند درست نمی‌شود.

دو راه‌حل:

**راه‌حل ۱ (پیشنهادی) — پروکسی خودت روی Cloudflare Workers، رایگان:**
```bash
cd proxy
npm i -g wrangler   # اگر نداری
wrangler login
wrangler deploy
```
آدرس `https://samimi-gems-proxy.<subdomain>.workers.dev` را در سایت،
**تنظیمات → آدرس پروکسی** بگذار. پروکسی فقط درخواست را رد می‌کند و
کلید را **ذخیره یا لاگ نمی‌کند**. همین اکانت Cloudflare که ربات روی آن
است کافی است.

**راه‌حل ۲ — پروایدر با CORS باز:** در تنظیمات، Base URL را به پروایدری
بده که CORS می‌دهد، مثلا OpenRouter:
`https://openrouter.ai/api/v1` + کلید OpenRouter خودت.

> از پروکسی‌های عمومی CORS (مثل corsproxy.io) برای کلید استفاده نکن —
> کلیدت دست یک واسطه ناشناس می‌افتد.

## استفاده

۱. **تنظیمات** → کلید API را وارد کن (کلید Nara با `sk-nry-` شروع می‌شود)
   و «تست اتصال» را بزن.
۲. اگر خطای CORS دیدی، آدرس پروکسی (بالا) را وارد کن.
۳. جم بساز یا همان `reply guy ✍️` را انتخاب کن و چت کن.
۴. با **ویرایش جم** می‌توانی پرامپت، دانش و کلمات ممنوعه را هر وقت عوض کنی؛
   با **پاک کردن حافظه** گفت‌وگوی آن جم را صفر کنی.

```
favicon.svg     # مارک جم
proxy/
  worker.js     # پروکسی CORS روی Cloudflare Workers (اختیاری)
  wrangler.toml # کانفیگ پروکسی
.nojekyll       # برای GitHub Pages
```

## امنیت

- کلید API هرگز در کد یا گیت نمی‌رود؛ فقط در مرورگر خود کاربر است.
